# Deskripsi Project Proyeksi Cash Flow Bulanan

Pada project ini saya menyusun **Proyeksi Cash Flow Bulanan PT Sinar Maju Jaya** menggunakan Microsoft Excel sebagai simulasi perencanaan arus kas perusahaan selama 12 bulan.

Tujuan dari project ini adalah menggambarkan bagaimana perusahaan dapat memonitor pergerakan kas masuk dan kas keluar setiap bulan, sehingga kondisi keuangan dapat dipantau lebih awal dan keputusan bisnis dapat dibuat dengan lebih terarah.

---

# Struktur Cash Flow yang Digunakan

Proyeksi ini saya bagi menjadi tiga bagian utama:

## 1. Kas Masuk

Kas masuk berasal dari:

* Pendapatan penjualan tunai
* Penerimaan piutang usaha sesuai jatuh tempo (due date)

Dengan metode ini, pendapatan tidak hanya dihitung dari penjualan bulan berjalan, tetapi juga memperhitungkan kapan kas benar-benar diterima.

---

## 2. Kas Keluar

Kas keluar terdiri dari beberapa komponen biaya operasional utama, yaitu:

* Pembelian persediaan
* Gaji karyawan
* Listrik, air, dan internet
* Sewa
* Pajak
* Biaya operasional lain-lain

Dengan pemisahan ini, perusahaan dapat melihat pengeluaran terbesar dan mengetahui area biaya yang perlu dikontrol.

---

## 3. Saldo Akhir Bulan Berjalan

Saldo akhir dihitung dari:

```text id="cflow1"
Total Kas Masuk - Total Kas Keluar
```

Hasil saldo menunjukkan apakah pada bulan tersebut perusahaan mengalami:

* Surplus kas (positif)
* Defisit kas (minus)

---

# Hasil Analisis dari Proyeksi

Berdasarkan simulasi yang dibuat, terdapat beberapa bulan dengan saldo negatif, yaitu:

* Januari : -8.150.000
* Juli : -3.250.000

Hal ini menunjukkan bahwa pada periode tersebut total pengeluaran lebih besar dibanding kas masuk yang diterima.

Sedangkan bulan lainnya masih menunjukkan posisi surplus kas.

---

# Fungsi Proyeksi Cash Flow Ini

Melalui file ini, perusahaan dapat menggunakan proyeksi cash flow untuk:

## 1. Mengetahui Kebutuhan Dana Lebih Awal

Jika terdapat bulan minus, perusahaan dapat menyiapkan cadangan kas sebelum periode tersebut terjadi.

## 2. Mengatur Jadwal Pembayaran

Pengeluaran seperti pembelian stok atau biaya operasional dapat dijadwalkan ulang agar tidak menekan arus kas pada bulan tertentu.

## 3. Mengontrol Pertumbuhan Biaya

Kenaikan biaya dari bulan ke bulan dapat dipantau dan dievaluasi.

## 4. Menentukan Target Penjualan

Jika kas masuk belum mencukupi, perusahaan dapat meningkatkan penjualan atau percepatan penagihan piutang.

## 5. Menjadi Dasar Pengambilan Keputusan

Cash flow projection dapat digunakan sebelum ekspansi, penambahan karyawan, pembelian aset, atau pembukaan cabang baru.

---

# Implementasi Jika Proyeksi Minus

Jika pada proyeksi terdapat saldo negatif, beberapa langkah yang dapat dilakukan antara lain:

## 1. Mempercepat Penagihan Piutang

Menindaklanjuti pelanggan yang memiliki jatuh tempo pembayaran agar kas masuk lebih cepat diterima.

## 2. Menunda Pengeluaran Non Prioritas

Biaya yang tidak mendesak dapat dijadwalkan ulang ke bulan surplus.

## 3. Menyesuaikan Pembelian Persediaan

Stok dibeli berdasarkan kebutuhan aktual agar dana tidak terlalu banyak tertahan di persediaan.

## 4. Menyiapkan Dana Cadangan

Surplus pada bulan lain dapat disisihkan sebagai buffer cash.

## 5. Menyusun Skema Pendanaan

Jika diperlukan, perusahaan dapat menyiapkan fasilitas pinjaman modal kerja jangka pendek.

# Pendekatan yang Digunakan di Excel

Dalam file ini saya menggunakan format bulanan agar data lebih mudah dibaca dan dianalisis. Dengan tampilan per bulan, manajemen dapat langsung melihat:

* Tren kenaikan penjualan
* Kenaikan biaya operasional
* Bulan rawan defisit
* Posisi surplus tahunan

Model ini juga dapat dikembangkan menjadi dashboard cash flow otomatis menggunakan formula Excel atau visual chart.
